# Milestone v1.0 Requirements

## Formulation & R&D
- [ ] **FORM-01**: Integrate an external AI/ML service for the in silico formulation scoring engine.
- [ ] **FORM-02**: Integrate an external molecule builder allowing scientists to draw molecules (must support 2D and 3D views, and be very easy to use).
- [ ] **FORM-03**: Allow users to test the drawn molecules using the formulation scoring engine.

## Supply Chain
- [ ] **SUPP-01**: Connect and ingest live external API data for supply chain resilience and shortage prediction.

## UI/UX & Integration
- [ ] **UIUX-01**: Add a comprehensive user guide to the left sidebar explaining how all platform features work.
- [ ] **UIUX-02**: Implement a Supabase backend proxy to securely fetch data from ChEMBL/PubChem (SMILES, ADMET).

## Compliance
- [ ] **COMP-01**: Establish 21 CFR Part 11 compliant audit trails for all data manipulations.
