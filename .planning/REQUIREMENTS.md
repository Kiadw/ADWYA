# Milestone v5.0 Requirements

## 1. SMILES Data & Molecule Viewer (MED)
- [ ] **MED-01**: Every one of the 45 medications must have a valid SMILES structure attached (no "Structure SMILES non disponible").
- [ ] **MED-02**: Molecule widget displays only the structure, removing all Ketcher drawing/editing tools.
- [ ] **MED-03**: Molecule widget restricts panning/zooming so the user cannot move the molecule out of the viewing frame.
- [ ] **MED-04**: Molecule widget includes a subtle button to toggle 3D view mode.

## 2. Supplier (Fournisseurs) Live Intelligence (FOU)
- [ ] **FOU-01**: Suppliers display real, live information indicating their saturation or availability level.
- [ ] **FOU-02**: Suppliers display real contact information (phone, email, website).
- [ ] **FOU-03**: Suppliers display their authentic company logo.
- [ ] **FOU-04**: Remove any explicit "Fournisseurs réel" labels; UI must treat real data implicitly without calling it out as real.
- [ ] **FOU-05**: Include a geographic map showing the provider's exact location, styled similarly to the molecule widget.
- [ ] **FOU-06**: Display molecule availability specifically based on real data for that supplier.

## 3. Global Constraints (GLO)
- [ ] **GLO-01**: STRICT ZERO MOCK DATA POLICY. All new data must be mapped to realistic/verified structures or real world values.
